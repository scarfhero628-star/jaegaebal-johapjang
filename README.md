## 휴대폰 홈 화면에 앱으로 설치
- **안드로이드(크롬·삼성 인터넷):** 주소를 열고 타이틀의 **[📲 앱으로 설치]**를 누르거나, ⋮ 메뉴 → **홈 화면에 추가**
- **아이폰(사파리):** 공유 버튼(□↑) → **홈 화면에 추가** → 추가
- 한 번 열어 두면 인터넷 없이도 할 수 있습니다. 처음 열 때 음악·대사 자료 약 17MB를 받습니다.
